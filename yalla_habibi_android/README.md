# Yalla Habibi Android App

A mobile-first restaurant ordering app branded in navy and gold, with menu categories, cart quantities, total calculation, and WhatsApp order handoff to **+92 325 8877188**. The logo is cropped from the supplied menu artwork. Menu prices reflect the supplied menu image.

## Build an APK (Android Studio)
1. Install Android Studio (current stable) and Android SDK Platform 35.
2. Open this folder (`yalla_habibi_android`) in Android Studio and allow Gradle sync.
3. Select **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. The debug APK will be generated at `app/build/outputs/apk/debug/app-debug.apk`.

Package: `pk.yallahabibi.app` · Version: `1.0.0` · Minimum Android: 6.0 (API 23).

## Important
This environment does not have Android SDK/Gradle installed, so an APK could not be compiled here. The complete Android Studio project is provided for building. The app currently sends orders to WhatsApp; online payments, live delivery tracking, and a restaurant admin backend are not included.
